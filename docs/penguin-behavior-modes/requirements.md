# 企鹅动作与陪伴模式 · 需求

对应技术设计：`architecture.md`。

## 背景

企鹅目前只有素材自带的呼吸循环，点击、玩耍和打盹主要依赖相似的整图变形，长期放在桌面上显得动作单一。参考同类桌宠常见的原地、散步、跟随和多情绪状态，增加可感知但不过度打扰的行为变化。

## 目标

- 增加“原地陪伴、自由散步、跟随鼠标”三种陪伴模式，并记住用户选择。
- 企鹅低频自主触发张望、摇摆走、滑行和打盹；正在移动时不叠加自主动作。
- 连续单击企鹅时在张望、摇摆和轻跳之间轮换，避免每次点击都是同一个反馈。
- 喂鱼显示小鱼靠近，双击或夸奖显示爱心，打盹显示逐渐飘走的 `Z z`。
- 跟随鼠标只读取系统光标坐标，缓慢靠近并在附近停下；不读取屏幕、窗口内容或键盘输入。
- 安静模式、专注状态、拖拽期间暂停窗口移动；隐藏或退出时清理所有计时器。
- 遵守 `prefers-reduced-motion`，用户要求减少动态效果时停用新增动画和特效。

## 验收标准

- 右键与托盘菜单可切换三种互斥模式，重启后保持选择。
- 旧设置中 `roaming: false` 迁移为“原地陪伴”，其他旧设置迁移为“自由散步”。
- 跟随鼠标时每 90ms 最多移动 8px，距离光标中心 90px 内停止，并始终保持在当前显示器工作区内。
- 企鹅自主动作间隔为 18–36 秒；其他角色继续使用原有 45–90 秒节奏。
- `npm run check`、`npm test` 通过，界面构建确认新增动作类型和减少动画规则可用。
