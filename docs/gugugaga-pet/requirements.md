# 咕咕嘎嘎动态桌宠需求

## 1. 目标

把仓库所有者提供的同一宝宝人物与动作参考图制作成一位免费内置动态桌宠，并设为首次启动的默认角色。角色在市场中显示为“咕咕嘎嘎”，延续参考图的圆脸、短黑发、大眼睛和丰富表情，通过同一组身份参考保持不同穿搭和动作的脸型一致。

## 2. 用户体验

- 角色可在免费宠物市场中直接选择，无账号、付费或联网要求。
- 待机使用米白上衣、蓝色书包造型并完成抬臂挥手循环；走动时切换黑色针织帽造型并逐帧交替迈步、摆臂。
- 单击依次触发托腮发呆、背带裤蹦跳和黄色小工人玩耍。
- 双击切换红帽开心姿势，长按切换猫咪滤镜，喂食/陪玩切换黄色小工人，夸奖切换双手合十，打盹切换云朵睡衣。
- 九种形态都必须有可见的手臂、腿、躯干或头部关节变化，不能仅对整张人物图做缩放或上下位移；动作结束后回到书包默认造型。
- 九套动作分别为：书包挥手、黑帽走路、睡衣伸懒腰、背带裤蹦跳、红帽大笑、小工人喝饮料、合十鞠躬、托腮晃脚、猫耳猫爪蹲跳。
- 安静模式、专注模式和“减少动态效果”系统偏好继续生效。

## 3. 素材与隐私

- 人物与动作参考图只用于生成角色母版，不在运行时上传或访问。
- 仓库保留 `assets/source/gugugaga*-reference.png` 身份/服装母版、`assets/source/gugugaga*-spritesheet.png` 九张 3×3 逐帧动作表及生成后的 GIF/WebM，不依赖抖音视频或远程素材。
- 内置素材随安装包离线分发；用户导入素材的现有本地保存规则不变。

## 4. 品牌头像

- 咕咕嘎嘎是项目主品牌，应用图标与安装包图标使用头部头像，不使用全身照。
- 头像保留短黑发、圆脸、大眼睛和蓝色书包肩带；图标在小尺寸下仍能辨认。
- `assets/brand/gugugaga-avatar.png` 是透明头像母版，`scripts/render-brand-icons.py` 负责生成运行时 PNG、Windows ICO 与 macOS ICNS。

## 5. 验收

- 市场共有 8 位内置角色，咕咕嘎嘎位于“沙雕日常”分类。
- `gugugaga-idle` 与八个变体均同时拥有 9 个姿势帧的 GIF 和透明 WebM，且相邻帧可观察到肢体关节变化。
- 桌宠窗口对九种形态优先播放 WebM，失败时回退对应 GIF。
- 首次启动显示咕咕嘎嘎；角色切换、点击、双击、长按、喂食、陪玩、夸奖、自主打盹和走动换装均正常。
- `npm run check` 与 `npm test` 通过；界面变更由 Electron smoke test 覆盖 8 张市场卡片。
- 托盘、通知、安装包和下载官网品牌位均显示咕咕嘎嘎头部头像。
