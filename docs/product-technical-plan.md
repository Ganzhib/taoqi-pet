# 淘气桌宠：产品与技术规划

## 1. 产品定位

淘气桌宠是永久免费、无需登录的桌面陪伴产品。宠物本身提供完整互动体验，用户可以主动从“我的工具”进入淘气工具铺，再选择简历、画图等独立产品。桌宠不设置付费角色、订阅、广告、强制跳转或以签到惩罚用户的机制。

首版面向日常办公和学习用户：启动即用、短暂互动、安静陪伴。基础功能离线运行，不读取屏幕、窗口内容、文件或浏览记录。

## 2. 用户流程

1. 启动后直接出现宠物，不弹登录或配置窗口。
2. 点击宠物获得即时反馈，拖动它到喜欢的位置；低频自主游走可暂停。
3. 右键或托盘菜单提供宠物市场、装扮、安静模式、置顶、大小、专注、工具入口和退出。
4. 只有用户点击“打开淘气工具铺”后，系统浏览器才访问 https://next.ganzhibin.icu/ 。
5. 返回桌面后，宠物继续之前的状态。

## 3. 当前代码结构

| 目录 | 职责 |
| --- | --- |
| src/electron/main.js | Electron 生命周期、窗口、菜单、本地设置与 IPC |
| src/electron/preloads/ | 桌宠、市场和小窝各自的最小桥接 |
| src/electron/pet-core.js | 角色元数据、工作区边界与受控工具地址 |
| src/ui/pet/ | React 桌宠界面、角色台词与动画 |
| src/ui/market/ | React 免费宠物市场 |
| src/ui/home/ | React 小窝、布置和抓鱼游戏 |
| src/ui/shared/ | 桥接 TypeScript 契约与共用 Hook |
| assets/pets/*.svg、build/icon.svg | 项目内置角色与应用图标 |
| tests/ | 核心逻辑测试与真实 Electron 窗口验收 |

Vite 从 `src/ui/` 的三个 HTML 入口构建到 `dist-ui/`，Electron 加载构建后的本地页面。主进程负责窗口坐标、用户图片副本和外部浏览器；React 负责动画、市场、小窝和临时交互状态。页面通过 contextIsolation 和独立 preload 调用有限 IPC，不直接调用 Node API。目录和文件命名规则见 [代码结构与命名约定](code-structure.md)。

## 4. 里程碑

### M0：可玩的基础版（当前）

- 宠物直接出现，点击和拖动有反馈。
- 低频游走、暂停、专注和置顶可控。
- 偏好本地保存；多显示器或分辨率变化后保持可见。
- 用户主动打开工具铺；无需账号和后台服务。

验收：首次启动不出现配置弹窗；拖动优先于游走；暂停或专注时不游走；地址只指向工具铺；退出后不遗留定时器。

### M1：角色与体验（核心完成）

- 已加入八位项目内原创 SVG 角色、免费宠物市场、装扮和主动互动。
- 已加入用户本地图片导入、选用、改名与删除；不上传用户素材。
- 已加入角色切换、安静模式、专注倒计时、托盘与位置恢复。
- 待完善中、英、日文案与辅助功能。
- 待完成 Windows、macOS、Linux 安装包的实机验收和发布签名。

### M2：长期留存（进行中）

- 已加入免费小窝：三种场景、三件家具、抱抱/跳舞/打盹和 20 秒抓鱼小游戏，布置与最佳成绩仅保存在本机。
- 待做可视化角色创作工具与更多小窝装饰。
- 待做桌面上的低频且可关闭的打盹、玩耍等自主动作。
- 用户自愿启用的外部产品联动。
- 根据明确告知与退出机制设计匿名统计；不采集聊天或设备身份数据。

## 5. 商业化边界

桌宠永久免费。商业化只发生在用户主动前往的独立产品中。首版通过工具铺统一入口承接简历、画图等需求；可以附加不含个人信息的来源参数，禁止定时弹窗、自动打开网页和与互动奖励绑定的导流。

## 6. AI 开发任务

1. 每次先读取当前代码、分支和本规划书，按可验收任务提交。
2. 当前开发直接提交 main，不创建 PR；提交信息为 <type>(<scope>): 中文描述。
3. 保持单一行为定时器的所有权；拖拽、暂停、专注和退出时清理或重排调度。
4. 新增角色或图标前核对公开分发权限；不复制参考项目的代码、图片或提交历史。
5. 完成改动后报告改动文件、GitHub Actions 结果、手工验收与未完成项。

## 7. 发布前检查

- 角色、图标与声音的权利清楚。
- Windows 和 macOS 实际验证透明窗口、拖拽、右键菜单、退出与工具入口。
- 检查离线启动、安装包名称、隐私说明和跨屏行为。
- 每次公开发布前核对文档、依赖与内置素材许可。
