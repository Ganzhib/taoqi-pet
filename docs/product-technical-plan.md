# 淘气桌宠：产品与技术规划

## 1. 产品定位

淘气桌宠是永久免费、无需登录的桌面陪伴产品。宠物本身提供完整互动体验，用户可以主动从“我的工具”进入淘气工具铺，再选择简历、画图等独立产品。桌宠不设置付费角色、订阅、广告、强制跳转或以签到惩罚用户的机制。

首版面向日常办公和学习用户：启动即用、短暂互动、安静陪伴。基础功能离线运行，不读取屏幕、窗口内容、文件或浏览记录。

## 2. 用户流程

1. 启动后直接出现宠物，不弹登录或配置窗口。
2. 点击宠物获得即时反馈，拖动它到喜欢的位置；低频自主游走可暂停。
3. 右键菜单提供置顶、大小、专注、工具入口和退出。
4. 只有用户点击“打开淘气工具铺”后，系统浏览器才访问 https://next.ganzhibin.icu/ 。
5. 返回桌面后，宠物继续之前的状态。

## 3. 当前代码结构

| 文件 | 职责 |
| --- | --- |
| src/main.js | Electron 生命周期、宠物窗口、菜单、位置与本地设置 |
| src/preload.js | 向宠物页面暴露有限的 IPC 能力 |
| src/renderer.js | 点击、拖拽、气泡与视觉状态 |
| src/pet-core.js | 工作区边界及受控工具地址 |
| src/index.html、src/styles.css | 宠物结构与动画 |
| tests/pet-core.test.js | 工作区边界与链接不变量 |

窗口保持透明、无边框；主进程负责窗口坐标和外部浏览器，渲染进程负责动画。使用 contextIsolation 和 preload，页面不直接调用 Node API。工具入口地址定义在主进程可访问的固定配置中，渲染进程不能传入任意 URL。

## 4. 里程碑

### M0：可玩的基础版（当前）

- 宠物直接出现，点击和拖动有反馈。
- 低频游走、暂停、专注和置顶可控。
- 偏好本地保存；多显示器或分辨率变化后保持可见。
- 用户主动打开工具铺；无需账号和后台服务。

验收：首次启动不出现配置弹窗；拖动优先于游走；暂停或专注时不游走；地址只指向工具铺；退出后不遗留定时器。

### M1：角色与体验

- 设计可公开分发的原创角色、图标和动作帧。
- 支持角色切换、安静模式及更丰富的触摸反馈。
- 完善中、英、日文案与辅助功能。
- Windows、macOS、Linux 安装包与手工验收。

### M2：长期留存

- 免费的小窝、装饰和角色创作工具。
- 低频且可关闭的打盹、玩耍等动作。
- 用户自愿启用的外部产品联动。
- 根据明确告知与退出机制设计匿名统计；不采集聊天或设备身份数据。

## 5. 商业化边界

桌宠永久免费。商业化只发生在用户主动前往的独立产品中。首版通过工具铺统一入口承接简历、画图等需求；可以附加不含个人信息的来源参数，禁止定时弹窗、自动打开网页和与互动奖励绑定的导流。

## 6. AI 开发任务

1. 每次先读取当前代码、分支和本规划书，按一个里程碑中的一个可验收任务提交。
2. 新分支使用用户指定的 ganzhibin/<type>/<english-description> 规则；提交信息为 <type>(<scope>): 中文描述。
3. 保持单一行为定时器的所有权；拖拽、暂停、专注和退出时清理或重排调度。
4. 新增角色或图标前核对公开分发权限；不复制参考项目的代码、图片或提交历史。
5. 完成改动后报告改动文件、GitHub Actions 结果、手工验收与未完成项。

## 7. 发布前检查

- 角色、图标与声音的权利清楚。
- Windows 和 macOS 实际验证透明窗口、拖拽、右键菜单、退出与工具入口。
- 检查离线启动、安装包名称、隐私说明和跨屏行为。
- 在用户决定公开仓库前，再核对文档与依赖许可。
