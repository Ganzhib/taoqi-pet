# 淘气桌宠 v0.2.0-preview.2

这是 Windows 与 macOS 的**未签名预览版**。桌宠本身全部免费，无需登录；基础互动和创作可离线使用。

## 这版能玩什么

- 八位原创角色、免费宠物市场、点击/长按/拖动互动和低频自主活动。
- 新增可视化捏宠：组合小猫、小龙、团子造型，自选颜色和三种表情，实时预览并保存在本机。
- 可导入 PNG、JPG、GIF、WebP 图片作为宠物，也可以给自定义宠物改名或删除。
- 淘气小窝有三种场景、五件家具、抱抱/跳舞/打盹和 20 秒抓鱼游戏。
- 支持安静模式、暂停活动、25 分钟专注、置顶、调整大小和系统托盘。
- 只有用户主动点击“我的工具”时，才打开淘气工具铺。

## 下载与安装

本版修正了下载文件名：每个文件都包含项目名、版本、系统和 CPU 架构。

- Windows：选择 `.exe` 安装程序或便携版。
- macOS：按芯片选择 `arm64`（Apple Silicon）或 `x64`（Intel）的 `.dmg`；`.zip` 是同架构的压缩包。

这些安装包没有代码签名，macOS 也未公证。系统可能显示安全提示。请只从本仓库的 Release 页面下载。当前 CI 已执行自动化检查；Windows 与 macOS 的实体设备安装和交互验收仍待完成。

## 数据与隐私

宠物图片、捏宠作品、小窝布置和偏好保存在本机，不会自动上传。预览版没有统计 SDK；不会读取屏幕、浏览记录或其他文件。工具铺入口仅在用户点击时打开。

## 已知限制

- 界面目前主要为中文；英语、日语和更完整的辅助功能仍在后续计划中。
- 未签名和未公证；正式版需要 Windows 与 Apple 证书。
- 暂无 Linux 安装包。
