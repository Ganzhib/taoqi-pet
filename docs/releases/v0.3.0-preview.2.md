# 淘气桌宠 v0.3.0-preview.2

这版加入新版本提醒和更新入口：

- Windows 安装版会定期检查 GitHub Release；发现新版本后后台下载，完成时通知，可选择立即重启安装或退出时安装。
- Windows 便携版、未签名 macOS 预览版会提示新版本并打开官方 Release 下载页。
- 托盘和宠物右键菜单增加手动“检查更新…”。

注意：v0.3.0-preview.1 尚未内置更新器，需要手动安装本版一次。Windows 的原地更新从本版升级到**下一个**版本时生效，仍需实机验收。macOS 自动原地更新需要正式代码签名；当前仍为未签名预览版。

所有宠物、角色、小窝与互动功能继续免费。桌宠只在用户主动点击“我的工具”时打开淘气工具铺。
