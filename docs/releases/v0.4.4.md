# 淘气桌宠 v0.4.4

这一版修复版本检查依赖 GitHub REST API 匿名额度的问题。共享网络出口的额度耗尽时，macOS 未签名版和 Windows 便携版曾经会直接显示“检查更新失败”。

## 版本发现

- 改用公开的 GitHub Releases Atom Feed 发现已发布版本，不再请求有匿名调用配额的 Releases API
- 正式版只选择正式 Release，预览版仍可选择后续预览版或转入正式版
- 版本标签继续只接受 `v主.次.修` 与 `v主.次.修-preview.序号` 两种格式
- Feed 返回异常或网络不可用时不会影响桌宠离线运行

## 下载与安装

- Windows NSIS 安装版确定候选版本后，直接读取该 Release 目录里的 `latest.yml` 或 `preview.yml`
- Windows 安装版继续支持后台下载，并在退出或确认重启时原地更新
- Windows 便携版和未签名 macOS 版发现新版后打开对应 Release 手动下载
- 手动检查失败时提供“打开发布页”，让用户仍有可执行的后续操作

## 从 v0.4.3 升级

v0.4.3 的 macOS 版已经包含旧检查逻辑，无法远程改写；macOS 用户需要从本 Release 手动安装 v0.4.4 一次。v0.4.4 之后的版本检查将使用新的公开 Feed。Windows v0.4.3 安装版可继续尝试原地更新，便携版也需要手动下载。

## 验证与安装

- 真实在线请求确认旧 REST API 在匿名额度耗尽时返回 403，而公开 Atom Feed 正常返回版本列表
- 单元测试覆盖 Feed 标签提取、预览版识别、版本排序与候选 Release 下载地址
- 自动代码检查、单元测试和 Electron smoke test 已通过
- Windows x64 与 macOS Intel / Apple Silicon 构建已通过
- 当前安装包尚未签名，macOS 也尚未公证；系统可能显示安全提示，请只从本仓库官方 GitHub Release 下载

构建成功不等于 Windows/macOS 实机安装验收。Windows 原地更新、macOS 手动覆盖安装和长期运行仍需在真实设备上分别验证。
