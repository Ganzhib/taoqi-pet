# 淘气桌宠 v0.4.5

这一版让用户导入的现成动图保留原有动作，并继续推进宠物工坊的产品规划。

## 动图导入

- GIF、APNG 和动态 WebP 导入时保留原始动画文件，不再把 APNG 或动态 WebP 作为静态图片抠图
- 静态 PNG、JPG、WebP 继续使用现有主体抠图流程
- 宠物市场在导入动图后说明原有动画已保留，作品可直接在桌面使用
- 多张连续帧、透明视频和完整宠物工坊仍在规划中，本版尚未提供这些导入入口

## 验证与安装

- 类型检查、44 项单元测试和 Electron 冒烟测试已通过
- 真实 Electron 流程验证两帧 APNG、动态 WebP 的原始文件被保留，并加载为桌宠素材
- Windows x64 提供安装版与便携版；macOS 提供 Apple Silicon 与 Intel 的 DMG/ZIP
- 安装包尚未签名，macOS 尚未公证；请从本仓库官方 GitHub Release 下载

发布工作流会在 Windows、macOS 安装包及自动更新清单齐全后公开版本。自动化验证不代替 Windows/macOS 实机安装与长期运行验收。
