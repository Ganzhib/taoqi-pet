# 淘气桌宠 v0.4.1

这一版重新设计咕咕嘎嘎九种造型的切换方式：换装由用户主动控制，人物互动和桌面走动不再擅自改变已选择的形象。

## 悬浮造型工具条

- 咕咕嘎嘎脚下新增独立的白色圆角胶囊工具条，样式与人物分离，不随人物缩放
- 点击衣服按钮打开九宫格，可直接选择蓝书包、黑帽、云朵睡衣、背带裤、红帽、小工人、双手合十、托腮和猫耳九种造型
- 点击轮换按钮可直接切换到下一种造型，当前选中项会在九宫格中高亮
- 造型选择保存在本机，退出并重新启动后仍会恢复；淘气小窝同步显示所选造型
- 单击、双击、长按、喂食、陪玩、夸奖、自主活动和走动继续提供即时动作与气泡反馈，但不再自动换装

## 官网部署调整

- 删除独立服务器、SSH、Nginx 和独立域名部署工作流
- 下载官网只保留 GitHub Pages 发布方式，不需要服务器密钥

## 验证与安装

- 自动检查、39 项单元测试和 Electron smoke test 已通过
- Windows x64 提供安装版与便携版
- macOS 提供 Apple Silicon 与 Intel 的 DMG/ZIP
- 当前安装包尚未签名，macOS 也尚未公证；系统可能显示安全提示，请只从本仓库官方 GitHub Release 下载

发布工作流验证 Windows、macOS 安装包和自动更新清单齐全后才会公开本版本。构建成功不等于 Windows/macOS 实机安装验收；未完成的实机验证会继续单独记录。
