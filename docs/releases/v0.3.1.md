# 淘气桌宠 v0.3.1

v0.3.0 的小幅修复。桌宠动画改用透明 WebM 后，多个旧链路里被覆盖掉的兼容问题在这一版集中修掉，并补回第 14 位内置角色。

## 修复

- **桌宠窗口能稳定显示动画了**。v0.3.0 之后启用透明 WebM 主路线，但内置 Electron 的某些构建无法解码带 alpha 的 VP9 视频，桌宠会回退到一个永远显示不出来的占位符。本版彻底修掉了这条降级链：播放失败时回退到 GIF（1 bit alpha，视觉回到旧观感），不会再卡在不可用状态
- **小窝页面和市场缩略图正常显示**。这两个页面的「图片素材」接口之前会被误指到视频源，`<img>` 解不出来导致空白
- **内置素材改用 `pet://` 自定义协议**。Chromium 默认拒绝从 `data:` URL 加载媒体资源，这是上一版残留问题的根因
- **正式版不再误升级到 preview 版**。正式版和预览版现在使用独立更新通道；预览用户仍可继续接收预览更新，并在正式版发布后平滑升级到正式版

## 新增

- **第 14 位内置角色「企鹅」**。从社区伙伴提供的素材抠出，12 帧呼吸动画，体积 31.4 KB。市场里可以选，点它的时候有专属台词

## 内部

- 把 13 个内置角色素材重新生成了一遍：WebM 合计 359 KB，对比 GIF 3670 KB，**降幅 90%**
- 抽出素材来源抽象层，将来需要换格式只改一个文件
- 冒烟测试增加视频解码探针，未来如果视频在某个平台上跑不起来，CI 会直接给出 `readyState / networkState / error` 而不是只显示超时

## 更新方式

由于 v0.3.0 正式安装版错误地固定在 preview 渠道，无法通过原有更新器安全切回正式渠道，需要手动安装一次 v0.3.1。之后的正式版只会接收正式更新。Windows 便携版和未签名 macOS 版同样需要手动下载安装。
