# 淘气桌宠 v0.4.3

这一版修复透明桌宠在焦点状态和造型切换过程中的两类视觉残影。

## 透明背景与焦点状态

- 删除包围整个宠物素材容器的紫色圆角矩形轮廓
- 键盘焦点提示改为沿角色透明轮廓显示的轻微光晕
- GIF/WebM 素材及 Electron 窗口继续保持透明背景
- 气泡、造型工具条和键盘操作保持可用

## 造型切换

- 角色或造型 ID 改变时立即卸载旧素材播放器
- 新素材加载完成后再挂载对应 GIF/WebM
- 已失效的异步加载结果不会覆盖当前选择
- 避免透明区域继续合成上一套造型的最后一帧

## 验证与安装

- 自动代码检查、41 项单元测试和 Electron smoke test 已通过
- Electron 回归截图确认蓝书包切换到黑帽后只保留新造型
- Windows x64 提供安装版与便携版
- macOS 提供 Apple Silicon 与 Intel 的 DMG/ZIP
- 当前安装包尚未签名，macOS 也尚未公证；系统可能显示安全提示，请只从本仓库官方 GitHub Release 下载

发布工作流验证 Windows、macOS 安装包和自动更新清单齐全后才会公开本版本。构建成功不等于 Windows/macOS 实机安装验收；未完成的实机验证会继续单独记录。
