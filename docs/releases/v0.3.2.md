# 淘气桌宠 v0.3.2

这一版把企鹅设为默认桌宠，精简内置角色并增加更自然的陪伴动作，同时修正正式版误跟随 preview 更新通道的问题。

## 角色与互动

- 默认角色改为企鹅，内置市场保留企鹅、橘白猫、小奶猫、打工狗、泡泡龙、蹦蹦兔和云朵团子七位免费伙伴
- 企鹅会低频张望、摇摆走、滑行和打盹；连续点击时反馈会轮换
- 新增原地陪伴、自由散步和跟随鼠标三种模式，并记住用户选择
- 喂鱼、夸奖和打盹加入更贴近角色的局部效果，互动气泡移到宠物头部附近
- 官网同步改为展示七位角色、本地图片导入和可视化捏宠，不再把产品限定为单一猫咪桌宠

## 修复与发布

- 正式版只接收正式更新，不再升级到 preview 预览版
- 预览版继续接收预览更新，并可在正式版发布后平滑转入正式版
- 显式禁止更新器跨通道降级，避免切换通道时产生意外回退
- 修复 Windows 环境下测试命令无法展开测试文件的问题

## 更新方式

v0.3.0 与 v0.3.1 的正式安装版错误地固定在 preview 渠道，无法通过原有更新器安全切回正式渠道，需要手动安装一次 v0.3.2。之后的正式版只会接收正式更新。Windows 便携版和未签名 macOS 版同样需要手动下载安装。

当前安装包仍未签名，macOS 也尚未公证；安装时系统可能显示安全提示。请只从本仓库的官方 GitHub Release 下载。
