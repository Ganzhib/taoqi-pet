# 淘气桌宠 v0.3.0-preview.1

Windows 和 macOS 的未签名预览版。桌宠全部功能免费、无需登录，基础互动可离线运行。

## 这次更新

- 以项目所有者提供的橘白猫形象替换原有八位内置角色。八种学习、打工与沙雕日常状态均为真正循环的 12 帧 GIF。
- 更新桌宠、托盘与安装包图标为同一只猫。
- 修复置顶层级；macOS 开启置顶时还能出现在其他空间和全屏应用上方。系统级安全界面及独占全屏游戏仍需分别实机验收。
- 新增 [下载官网](https://pet.ganzhibin.icu/)；官网的实际可访问性以 DNS 与 HTTPS 部署完成后的检查结果为准。
- 自定义图片导入、可视化捏宠、小窝、专注和工具铺主动入口改用 Electron 内置窗口打开，简历、画图等页面可在应用内使用。

## 下载

- Windows x64：`taoqi-pet-setup-0.3.0-preview.1-win-x64.exe` 安装版，或 `taoqi-pet-portable-0.3.0-preview.1-win-x64.exe` 便携版。
- macOS Apple Silicon：`taoqi-pet-0.3.0-preview.1-mac-arm64.dmg`。
- macOS Intel：`taoqi-pet-0.3.0-preview.1-mac-x64.dmg`。
- macOS 两种架构还提供 ZIP 压缩包。

安装包尚未代码签名，macOS 也未公证。系统可能显示安全提示，请只从本仓库下载。CI 自动化检查不等同于 Windows/macOS 实机安装验收。

角色 GIF 与图标来自仓库内可复现的素材脚本和所有者提供的原图；角色素材不自动上传。预览版没有遥测或广告 SDK。
