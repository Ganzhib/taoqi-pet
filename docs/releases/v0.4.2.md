# 淘气桌宠 v0.4.2

这一版移除 macOS 的桌面壁纸层模式，避免桌宠在桌面层与普通应用窗口之间出现不符合预期的层级行为。

## 窗口模式简化

- 删除“桌面层（点桌面不会被推走）”菜单选项
- 删除 Electron `desktop` 窗口类型与相关重建窗口逻辑
- 只保留“总在最前”和“普通窗口”两种窗口模式
- 旧版本保存的 `desktopLevel` 设置会被忽略，并在下次保存设置时清理
- 置顶、拖动、互动、托盘隐藏、专注计时和其他桌宠功能保持可用

## 验证与安装

- 自动代码检查、单元测试和 Electron smoke test 已通过
- Windows x64 提供安装版与便携版
- macOS 提供 Apple Silicon 与 Intel 的 DMG/ZIP
- Windows 安装版可通过正式更新通道下载并原地安装本版本
- 当前安装包尚未签名，macOS 也尚未公证；系统可能显示安全提示，请只从本仓库官方 GitHub Release 下载

发布工作流验证 Windows、macOS 安装包和自动更新清单齐全后才会公开本版本。构建成功不等于 Windows/macOS 实机安装验收；未完成的实机验证会继续单独记录。
