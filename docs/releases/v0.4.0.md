# 淘气桌宠 v0.4.0

这一版把咕咕嘎嘎正式设为淘气桌宠的默认主角与项目品牌，并把原先只有整图位移的表现升级为九套有手臂、腿、躯干和头部变化的逐帧肢体动画。

## 咕咕嘎嘎主品牌

- 首次启动默认显示咕咕嘎嘎，宠物市场仍保留企鹅、猫咪、小狗、小龙、兔子和团子等 8 位免费伙伴
- 应用图标、安装包图标、托盘、通知和官网品牌位统一使用咕咕嘎嘎头肩头像，不用全身照充当商标
- 官网首屏改为展示咕咕嘎嘎动态形态，并继续提供本地图片导入与可视化捏宠

## 九套逐帧肢体动作

- 默认蓝书包造型会抬臂挥手，并伴随屈膝和重心变化
- 黑色毛线帽造型会交替迈步、抬脚和摆臂
- 云朵睡衣会揉眼、举臂伸懒腰和打哈欠
- 背带裤造型会屈膝蹦跳、抬腿、张臂和拍手
- 红帽造型会握拳、屈膝、抖肩并仰头大笑
- 黄色小工人会举杯喝饮料，放下后竖起拇指
- 合十造型会抬手、弯膝并鞠躬
- 托腮造型会转头、眨眼、轻抬一只脚
- 猫耳滤镜造型会做猫爪、蹲下并跳起

每套动作均包含 9 个姿势帧，同时提供透明 WebM 主素材和 GIF 降级素材。单击、双击、长按、喂食、陪玩、夸奖、打盹和走动会切换到对应动作。
