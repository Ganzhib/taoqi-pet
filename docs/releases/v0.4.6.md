# 淘气桌宠 v0.4.6

这一版把已有制作能力放进能直接找到的宠物工坊。

## 宠物工坊入口

- 桌宠右下角新增常驻“制作”按钮；右键菜单和系统托盘增加“制作宠物…”
- 工坊分成“发现伙伴”“制作宠物”“我的宠物”三个区域，保留原有 M 键打开发现伙伴
- 制作页可从模板捏宠，或导入 PNG、APNG、JPG、GIF、WebP；保存后立即切换桌宠
- 我的宠物集中显示已保存的作品，支持选用、改名和删除
- 多张连续帧、视频导入和单图动效编辑仍在开发中，本版没有这些能力

## 验证与安装

- 类型检查、单元测试和 Electron 冒烟测试覆盖了桌宠入口、工坊页面切换、模板制作与导入后的立即使用
- Windows x64 提供安装版与便携版；macOS 提供 Apple Silicon 与 Intel 的 DMG/ZIP
- 安装包尚未签名，macOS 尚未公证；请从本仓库官方 GitHub Release 下载

发布工作流会在 Windows、macOS 安装包及自动更新清单齐全后公开版本。自动化验证不代替 Windows/macOS 实机安装与长期运行验收。
