# 淘气桌宠 v0.3.0

首个正式版。宠物市场在橘白打工猫的八种状态之外，新增五位动物伙伴；导入自己的静态图片时自动抠图，只保留宠物主体。全部功能依旧免费、免登录、不读隐私。

## 新增内容

- 市场新增小奶猫、打工狗、泡泡龙、蹦蹦兔、云朵团子五位动物伙伴，内置小伙伴共 13 位；每位都有各自的互动文案，支持选它陪伴、改名、删除与小窝互动
- 导入 PNG、JPG、WebP 图片时自动去除背景。抠图在本机完成，图片不上传；没有明显背景时保留原图并提示
- 新增角色的动图由 `scripts/render-friend-gifs.py` 程序化绘制，与既有橘白猫同一套画风，版权与仓库一致

## 更新方式

Windows 安装版保留新版提醒、后台下载和重启安装；已安装 v0.3.0-preview.2 及之后版本的用户可通过菜单“检查更新…”获取本版。Windows 便携版和未签名 macOS 版需手动下载安装。

## 已知情况

- 安装包尚未签名，macOS 也尚未公证，两个平台都可能显示系统安全提示
- 自动更新清单沿用 preview 通道，桌面端的版本提醒与 Windows 原地更新行为不变
- 导入的 GIF 暂不支持抠图，逐帧编解码在后续版本评估
- 各平台安装后的实机验收仍需单独推进；代码签名与公证也在推进中
