# 淘气桌宠 v0.4.7

这一版修复浅色桌面壁纸上宠物轮廓出现灰紫色残影的问题。

## 修复

- 移除桌宠通用容器和键盘焦点时叠加在透明素材上的轮廓阴影；黑帽走路等内置造型与用户导入的透明作品共用这项修复
- 键盘操作时改用独立的小圆点标明焦点，专注模式仍保留原有的低饱和度效果

## 验证与安装

- 透明 WebM 原帧与 Electron 窗口截图在白底上分别对照，确认残影来自界面样式而非素材
- 类型检查、单元测试和 Electron 冒烟测试通过；桌宠焦点效果有回归断言
- Windows x64 提供安装版与便携版；macOS 提供 Apple Silicon 与 Intel 的 DMG/ZIP
