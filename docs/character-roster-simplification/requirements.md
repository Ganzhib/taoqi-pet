# 内置角色精简与企鹅默认角色 · 需求

> 后续变更：咕咕嘎嘎动态桌宠加入后，默认角色已改为 `gugugaga-idle`，内置目录增至 8 位；最新要求见 [`../gugugaga-pet/requirements.md`](../gugugaga-pet/requirements.md)。本文件保留当时从多猫状态精简到七位角色的历史决策。

对应技术设计：`architecture.md`。

## 背景

桌宠的“快速切换角色”和宠物市场同时展示同一只橘白猫的八种状态，列表较长且角色区分度不足。企鹅已经作为独立内置角色加入，适合作为应用首次启动时的默认形象。

## 目标

- 内置角色目录只保留“发呆猫”这一只橘白猫，不再展示冲刺猫、赶工猫、咖啡续命猫、修 Bug 猫、摸鱼猫、装睡猫和下班猫。
- 企鹅排在内置角色目录首位，并作为新安装、设置文件缺失或角色选择失效时的默认角色。
- 小奶猫、打工狗、泡泡龙、蹦蹦兔、云朵团子和用户自定义宠物保持不变。
- 已保存的下架猫咪状态在升级后自动迁移为企鹅；有效的自定义角色选择继续保留。
- 互动气泡贴近宠物头顶；调整宠物大小时不再随着窗口变高而远离宠物。
- 官网仍可继续使用历史猫咪状态素材，本次不删除对应 GIF/WebM 文件。

## 验收标准

- 全新用户启动后显示企鹅。
- “快速切换角色”和宠物市场共有 7 个内置角色，其中 `cat-` 前缀只剩 `cat-idle`。
- 保存了任一下架猫咪状态的旧设置，重新启动后显示企鹅。
- 删除当前选中的自定义宠物后回到企鹅。
- 1 倍、1.25 倍和 1.5 倍大小下，互动气泡与宠物头顶的视觉间距保持在约 12px 内。
- `npm run check`、`npm test` 通过；Electron 冒烟测试验证默认企鹅、7 张内置卡片、切换发呆猫和删除自定义宠物后的回退行为。

## 非目标

- 不删除官网仍在展示的历史猫咪动图素材。
- 不改变用户本地导入、捏宠、装扮、小窝或外部工具入口。
- 不新增付费、登录、遥测或自动打开外部产品的行为。
