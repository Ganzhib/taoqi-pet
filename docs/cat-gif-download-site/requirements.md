# 桌宠动图与下载官网：需求

## 背景与目标

本需求最初用于把旧版 SVG 角色替换为可循环播放的橘白猫动图，并补齐 Windows/macOS 下载官网。产品后来已经扩展为以咕咕嘎嘎为主品牌和默认桌宠、8 位免费内置伙伴、本地图片导入和可视化捏宠；官网以咕咕嘎嘎为首屏主角，同时保留自由选择和自定义能力。

官网的核心目标是让访客依次理解三件事：可以从免费角色中选择、可以导入自己的图片、也可以亲手创作角色，然后再下载适合当前系统的安装包。

## 用户故事与验收

1. 用户打开桌宠后默认看到咕咕嘎嘎，可在市场中切换咕咕嘎嘎、企鹅、橘白猫、小奶猫、打工狗、泡泡龙、蹦蹦兔和云朵团子。用户已有自定义图片与捏宠数据继续保留。
2. 用户访问官网时，首屏标题、说明、导航、角色展示、功能说明和下载引导均以“可自定义桌宠”为主线，不把猫作为产品的固定主角。
3. 官网角色区展示 8 位免费内置伙伴；默认演示角色与桌宠默认值保持一致，为咕咕嘎嘎。导航品牌标记使用咕咕嘎嘎头部头像。
4. 官网明确说明用户可以导入 PNG、JPG、GIF、WebP 图片或通过造型、颜色、表情捏宠；用户素材只保存在本机，不会静默上传。
5. 开启“总在最前”后，宠物应出现在一般应用窗口上方。macOS 还应显示在其他空间和全屏应用上方；关闭选项后恢复普通层级。Windows、macOS 实机分别验收，系统级安全界面和独占全屏游戏单独记录。
6. GitHub Pages 官网展示主要免费功能、Windows 与 macOS 对应下载按钮，以及未签名版本说明；移动端也能使用。所有下载链接指向本仓库 GitHub Release。
7. 官网品牌区域使用中性的“淘气桌宠”字标，不用任一具体动物充当唯一品牌角色。官网演示动图遵守 `prefers-reduced-motion`，键盘可以选择角色。
8. 桌宠全部功能继续免费、无账号和后台遥测；淘气工具铺只在用户主动点击时于 Electron 内置窗口打开；简历、画图等工具不嵌入桌宠主窗口。

## 既有橘白猫素材约束

原图的可见猫爪结构不变，不使用生成式图片中多余肢体的版本。Windows 安装版和便携版继续使用完整、可解码的多尺寸 ICO；macOS 应用和 DMG 使用完整、可解码的 ICNS。构建前检查图标格式、尺寸及文件完整性，实机分别查看下载文件、安装后的应用和系统托盘/Dock 图标。应用安装图标属于既有发行资产，不代表官网产品定位绑定某一种动物。

## 非目标

本轮不提供 Linux 安装包，不增加付费角色或自动弹出的导流。官网无需账号、数据库或追踪 SDK，也不在官网实现真实的图片上传或在线捏宠功能。

## 发布门槛

`npm run check`、`npm test` 和真实 Electron 窗口验收通过；Windows/macOS 包与头像图标构建通过；Release 文件及 GitHub Pages 官网链接可访问。官网打包必须包含 8 个 `*-idle.gif` 角色素材和咕咕嘎嘎头像，并验证默认咕咕嘎嘎动图可访问。不能把代码提交当成 Pages 线上部署成功。
