# 橘白猫动图与下载官网：需求

## 背景与目标

旧版八个内置 SVG 角色与用户给出的橘白猫形象不一致。新版本以用户提供的 `catbuddy_apple_touch.png` 为唯一内置角色原型，制作多种学习、打工和沙雕状态的循环 GIF，替换旧角色和应用图标；同时改善桌宠的悬浮行为并提供 Windows/macOS 下载官网。

## 用户故事与验收

1. 用户打开桌宠后看到橘白猫，而不是旧版卡通角色。市场中的八个内置选项分别为待机、学习、赶工、咖啡、修 Bug、摸鱼、打盹和庆祝。每个资源是至少两帧的真实 GIF，持续循环；用户已有自定义图片与捏宠数据继续保留。
2. 开启“总在最前”后，宠物应出现在一般应用窗口上方。macOS 还应显示在其他空间和全屏应用上方；关闭选项后恢复普通层级。Windows、macOS 实机分别验收，系统级安全界面和独占全屏游戏单独记录。
3. 官网 `pet.ganzhibin.icu` 应展示真实 GIF 状态、主要免费功能、Windows 与 macOS 对应下载按钮，以及未签名预览版说明；移动端也能使用。所有下载链接指向本仓库 GitHub Release。
4. 原图的可见猫爪结构不变，不使用生成式图片中多余肢体的版本。图标使用同一只猫。
5. 桌宠全部功能继续免费、无账号和后台遥测；淘气工具铺只在用户主动点击时于 Electron 内置窗口打开；简历、画图等工具不嵌入桌宠主窗口。

## 非目标

本轮不提供 Linux 安装包，不增加付费角色或自动弹出的导流。官网无需账号、数据库或追踪 SDK。

## 发布门槛

`npm run check`、`npm test` 和真实 Electron 窗口验收通过；Windows/macOS 包与图标构建通过；Release 文件及官网链接可访问。域名 DNS、HTTPS 和服务器部署分别核验，不能把代码提交当成线上部署成功。
