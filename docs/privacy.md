# 隐私说明

淘气桌宠无需账号，没有遥测、广告 SDK 或后台服务。基础互动和宠物市场的内置角色均可离线使用。

## 保存在本机的数据

- 偏好、当前角色、位置、专注结束时间与自定义角色名称保存在 Electron 的 userData 目录下的 settings.json。
- 用户导入的图片会复制到同一目录的 pets 子目录。原始图片路径不会写入配置，也不会上传。
- 在宠物市场删除自定义角色时，会删除这份本机副本；原始图片不受影响。
- 卸载程序后，操作系统可能保留 userData 目录，可按需自行删除。

## 网络访问

桌宠不会自动打开网页。只有用户点击菜单中的“淘气工具铺”时，才通过系统浏览器访问 https://next.ganzhibin.icu/ ，并附带固定的来源参数。独立工具铺的隐私规则以其页面说明为准。

桌宠本身不读取屏幕内容、窗口标题、浏览记录或用户文档。导入图片仅在用户主动选取文件时读取。
