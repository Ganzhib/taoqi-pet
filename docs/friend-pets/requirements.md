# 动物伙伴扩展与导入自动抠图 · 需求

归入文件夹：`docs/friend-pets/`。本文描述需求，技术实现见同目录 `architecture.md`。

## 背景

宠物市场此前只有同一只橘白猫的八种循环 GIF 状态。用户希望市场里有更多形象，并希望导入自己的图片时能一键去掉背景，只留下宠物主体。

## 目标

- 新增 5 个原创动物基础形态：小奶猫、打工狗、泡泡龙、蹦蹦兔、云朵团子，全部为循环动图。
- 新形象与现有橘白猫保持同一套视觉语言（INK 描边、奶油色高光、柔和 pastel 填充）。
- 每个新形象只包含宠物本身：透明背景、无道具、无文字、无边框，画面按宠物 bounding box 收紧后重新居中。
- 导入静态图片（PNG / JPG / WebP）时自动抠图；抠不掉时保留原图并明确告知用户。

## 非目标

- 不引入任何第三方素材。仓库政策要求内置角色必须有公开分发权，新形象由 `scripts/render-friend-gifs.py` 程序化绘制，版权与仓库一致（MIT）。
- 不做联网识别、不上传图片，抠图完全在本地完成。
- GIF 导入本期不抠图（逐帧编解码依赖另行评估），导入后保留原始动图。
- 不改动免费定位：无账号、无付费解锁。

## 验收标准

- 市场中内置角色从 8 个增加到 13 个，分类沿用 学习中 / 打工中 / 沙雕日常。
- 每个新角色都有对应 GIF，且通过 `tests/pet-core.test.js` 的既有校验（GIF89a、至少两帧）。
- 每个新角色都有互动文案（`src/ui/pet/reactions.ts`），缺失时回退到发呆猫。
- 导入静态图片后：有明确背景的图片完成抠图并提示；无明显背景的图片保留原图并提示。
- `npm run check`、`npm test` 通过；CI 的 Electron 冒烟测试通过（市场卡片数量同步更新为 13）。
