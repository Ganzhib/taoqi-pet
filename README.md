# 淘气桌宠

一只轻量、免费的桌面小伙伴。启动后就能看到宠物；单击、双击或长按会得到不同回应，拖动可以换位置，右键或从系统托盘可以切换角色与装扮、开启安静模式、开始专注或退出。所有桌宠功能均免费，无需账号，基础互动可离线使用。

需要简历、画图等工具时，可由用户从菜单的“我的工具”主动打开[淘气工具铺](https://next.ganzhibin.icu/)。

## 当前功能

- Windows、macOS、Linux 桌面窗口基础支持
- 透明窗口、拖动、单击/双击/长按反馈、待机和低频游走
- 宠物市场提供八位原创角色，含日常陪伴、动漫感和搞笑梗分类；全部免费
- 支持导入自己的 PNG、JPG、GIF、WebP 图片作为宠物，保存在本机，可随时删除
- 星星、蝴蝶结和小花等免费装扮
- 可主动喂小鱼、陪玩或夸夸它；没有饥饿值、签到或付费解锁
- 暂停游走、安静模式、置顶、调整大小、可恢复的 25 分钟专注计时
- 系统托盘隐藏与唤回、单实例运行、记住上次位置
- 打包后可在 macOS 和 Windows 菜单中选择开机启动
- 本地保存偏好与专注结束时间，不收集屏幕、文件或浏览记录
- 固定的外部工具入口，只有用户点击后才打开浏览器

## 运行

需要 Node.js 22 或更新版本。

    npm install
    npm start

检查代码与核心逻辑：

    npm run check
    npm test

生成当前系统的安装包：

    npm run dist

也可在 GitHub Actions 的 “Build desktop packages” 运行记录中下载 Windows、macOS 和 Linux 的测试构建。

产品定位、技术设计与后续任务见[产品与技术规划](docs/product-technical-plan.md)。
