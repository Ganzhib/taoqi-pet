# 淘气桌宠

一只轻量、免费的桌面小伙伴。启动后就能看到宠物；单击、双击或长按会得到不同回应，拖动可以换位置，右键可以切换角色、暂停游走、开始专注或退出。所有桌宠功能均免费，无需账号，基础互动可离线使用。

需要简历、画图等工具时，可由用户从右键菜单的“我的工具”主动打开[淘气工具铺](https://next.ganzhibin.icu/)。

## 当前功能

- Windows、macOS、Linux 桌面窗口基础支持
- 透明窗口、拖动、单击/双击/长按反馈、待机和低频游走
- 焦糖猫、星夜猫、薄荷猫三种免费外观，右键切换并本地记住选择
- 暂停游走、置顶、调整大小、25 分钟专注
- 本地保存偏好，不收集屏幕、文件或浏览记录
- 固定的外部工具入口，只有用户点击后才打开浏览器

## 运行

需要 Node.js 22 或更新版本。

    npm install
    npm start

检查代码与核心逻辑：

    npm run check
    npm test
