# 淘气桌宠

一只轻量、免费的桌面小伙伴。启动后就能看到宠物；单击、双击或长按会得到不同回应，拖动可以换位置，右键或从系统托盘可以切换角色与装扮、开启安静模式、开始专注或退出。聚焦宠物后按 M 可以打开宠物市场，按 H 可以进入淘气小窝。所有桌宠功能均免费，无需账号，基础互动可离线使用。

需要简历、画图等工具时，可由用户从菜单的“我的工具”在 Electron 内置窗口打开[淘气工具铺](https://next.ganzhibin.icu/)。

## 当前功能

- Windows、macOS 桌面窗口支持
- 透明置顶窗口、macOS 全屏空间显示、拖动、单击/双击/长按反馈、待机、低频游走，以及可随“暂停自主活动”关闭的打盹和玩耍
- 默认使用咕咕嘎嘎；形象脚下的悬浮胶囊工具条可打开九宫格主动选择，或一键轮换书包挥手、黑帽走路、睡衣伸懒腰、背带裤蹦跳、红帽大笑、小工人喝饮料、合十鞠躬、托腮晃脚和猫爪蹲跳九套逐帧造型，选择会保存在本机；宠物市场另有企鹅及六位动物伙伴，全部免费
- 支持可视化捏宠：自由组合小猫、小龙、团子造型、颜色与表情；也能导入自己的 PNG、JPG、GIF、WebP 图片，静态图片导入时自动抠图，只保留宠物主体。作品保存在本机，可改名或删除
- 淘气小窝支持三种场景、五件家具、抱抱/跳舞/打盹，以及免费的 20 秒抓鱼小游戏；小窝布置和最佳成绩只保存在本机
- 星星、蝴蝶结和小花等免费装扮
- 可主动喂小鱼、陪玩或夸夸它；没有饥饿值、签到或付费解锁
- 咕咕嘎嘎的换装由用户通过形象下方工具条控制，点击、双击、长按、喂食、陪玩、夸奖、打盹和走动只做即时动作与反馈，不改变已选造型；企鹅保留张望、摇摆走和滑行；支持原地陪伴、自由散步、跟随鼠标三种模式
- 安静模式、置顶、调整大小、可恢复的 25 分钟专注计时
- 关闭宠物窗口时隐藏到系统托盘，可随时唤回；单实例运行并记住上次位置
- 打包后可在 macOS 和 Windows 菜单中选择开机启动
- 本地保存偏好与专注结束时间，不收集屏幕、文件或浏览记录
- 固定的工具铺入口，只有用户点击后才在独立的 Electron 窗口打开
- 安装版启动后定期检查版本；正式版只接收正式更新，预览版可接收预览更新并在正式版发布后转入正式版。Windows 安装版后台下载并在退出或确认重启时原地更新，macOS 和 Windows 便携版发现新版后提示下载

## 规划中的宠物工坊

下一阶段计划把图片导入、可视化捏宠和作品管理整合成应用内的宠物工坊：导入图片后检查主体，预览自然的单图动效，保存后直接在桌面使用；需要抬手、走路等独立肢体动作的作品再进入分层编辑。现有内置伙伴、小窝、互动和桌面偏好会围绕作品复用，所有宠物功能继续免费、默认保存在本机。此功能尚未发布，现有静态图片导入能力仍按上方“当前功能”说明运行。产品取舍与阶段验收见[宠物工坊规划](docs/pet-studio/requirements.md)。

## 运行

需要 Node.js 22.12 或更新版本。界面使用 React、TypeScript 和 Vite；Electron 主进程与预加载脚本按运行边界分离。

    npm install
    npm start

检查代码与核心逻辑：

    npm run check
    npm test

开发环境中的真实窗口验收（CI 在 Linux 图形环境自动执行）：

    xvfb-run -a npm run smoke

验收使用临时用户数据目录，会实际执行选宠、导入、改名、删除与关闭窗口操作，并把截图写到 `artifacts/`。

生成当前系统的安装包：

    npm run dist

也可在 GitHub Actions 的 “Build desktop packages” 运行记录中下载 Windows 和 macOS 的测试构建。当前可访问的[下载官网](https://ganzhib.github.io/taoqi-pet/)由 GitHub Pages 托管，以咕咕嘎嘎和可自定义桌宠为主线；桌面应用提供 8 位免费内置伙伴、本地图片导入与可视化捏宠。

产品定位、技术设计与后续任务见[产品与技术规划](docs/product-technical-plan.md)。新增页面和角色时请遵循[代码结构与命名约定](docs/code-structure.md)。

## 发布状态

[v0.4.3](https://github.com/Ganzhib/taoqi-pet/releases/tag/v0.4.3) 是当前正式版：修复宠物获得焦点后出现包围整个素材容器的紫色圆角方框，以及切换造型时旧透明视频帧短暂残留的问题；造型工具栏改为鼠标进入桌宠窗口时出现，并兼顾键盘与触摸操作。焦点提示现在沿角色透明轮廓显示，造型切换会先卸载旧播放器，再在新素材加载完成后显示。Windows 安装版可接收原地更新；macOS 当前为未签名、未公证安装包，需要手动安装新版本。两个平台都可能出现系统安全提示。发布构建与真实设备安装验证分别记录；尚未完成的实机验收会继续推进。

更新机制的适用范围和发布流程见[自动更新设计](docs/auto-update/requirements.md)。本地数据与外部链接说明见[隐私说明](docs/privacy.md)。
